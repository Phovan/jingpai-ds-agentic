# 会话与入口增量设计

本轮保留现有导航、工作台、详情和三列首页，不重新制作设计稿。

- 登录：与应用一致的炭灰侧区、浅色角色区，酒红只用于主按钮和选中标记；现有白色透明 Logo 保留。
- 标识：浏览器图标使用酒红底白标；左上角品牌名之前显示透明白标。
- 首页：栏目标题与简短说明/筛选同行、不换行；移除周期卡底部和首页底部的重复说明。全局仍保留演示数据提示。
- 回答：一句结论在上，事实/影响/下一步在两列紧凑信息区；长依据默认折叠，引用仍能下钻。新回答先显示“整理上下文 / 核对记录 / 生成建议”等状态，再分块逐步输出；这是本地演示进度，不披露模型内部推理。历史消息不重复播放，支持直接查看完整回答。
- 新增：会话提出新增项目、需求等 → 草稿卡，核对类型、名称、目标、关联记录 → 确认提交或取消。字段缺失阻止提交；服务逻辑重验角色和关联权限；成功后保存唯一 ID 与审计记录，并提供“查看详情”。不以新增草稿代替立项或范围批准。刷新保留，重复点击不重复建记录。

只验证本轮桌面主路径、窄宽度布局及新增动作边界，不重新跑全场景或真实外部系统流程。
