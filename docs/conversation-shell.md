# 对话主界面调整 · V0.1.1

依据本轮用户要求及原始参考：`02.解决方案/调研后合作方案与建议/NAVI界面Demo - 管理层视图.html`。沿用 000 通识原则和现有业务状态机；不采用 NAVI 示例项目数字作为客户事实。

## 布局与入口

左侧固定 248px：劲牌企业大脑 → 新对话 → 工作台 → 最近对话及自定义分组；底部从上到下为反馈意见、设置。角色切换、导出和重置放入设置。六角色登录均进入对话首页。

中间：NAVI 式每日简报 → 与角色相关的关注事项 → 可追问的依据与行动 → 对话输入区。历史对话可继续，回答标记事实快照版本；问答本身不修改业务状态。

右侧：产出 / 输入材料面板，默认收起，顶部按钮展开。产出为显式生成的追踪摘要；输入支持粘贴文本并保存在本机，不声称已被真实模型解析。移动端以可关闭的模态面板显示。

## 工作台

优先展示角色跟进对象：管理层及 PMO 为项目组合，项目经理为项目与关联系统，Owner 和产品为需求，研发为系统与需求。每行显示领域、目标、实际 / 差距、状态和下一步。

领域包括研发、产品、营销、服务、采购、运营及未分类；支持领域、对象类型、状态和关键词组合筛选，按领域分组折叠，分页显示。分类仅是 Demo 设定，数量从实际展示对象统计，不虚构客户全量项目已接入。

工作台提供业务工具入口；原项目、需求、系统、报告、经验库、执行中心不再出现在左侧菜单。对象与工具均可添加关注，快捷入口保存在各角色自己的工作台。未接入的组合示例只读展示，不能误跳至订单项目。

## 状态与边界

对话、分组、关注、输入材料和反馈按演示角色隔离并本机保存；业务事实仍跨角色共享。空对话不重复生成历史；分组可新建、重命名、折叠，并可移动对话。反馈仅本地留存，不声称已提交给服务端。

本轮先以此规格作为设计检查依据，不继续未经确认的 Figma 页面捕获，不同步知识库。验收包含六角色入口、分组持久化、工作台筛选与关注、材料开合、原业务动作以及桌面 / 手机布局。
