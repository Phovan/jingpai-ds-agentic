## 本轮交互

1. 首页周期汇报的第五个入口为自定义 Topic；种子主题覆盖评论处置、供应商回执、AI 工程质量、品牌出海准备，并允许新建。
2. 工作台详情按战略拆解、项目交付和软件生命周期组织 Tab；项目成本/人天分表列，员工在项目中显示为相关成员/干系人。
3. 两种输入框均支持 `/` 示例问题，例子来自当前对象或当前清单。回答后可点击相邻问题继续；焦点和来源会话持续保留。
4. 回答中的授权对象名称和编号高亮，可下钻详情；前进/后退保留。文本按 React 转义渲染，不执行资料中的 HTML。
5. 对話由本地事实与规则生成：优先核对证据，再判断影响、范围和行动，明确谁确认。自由问答不是通用 LLM；不支持的实际业务写操作不会伪造成功回执。
6. 研发由 D01 → I01 发起“开始EOS实施”，右侧查看归因、研发、Review、验证；r1 退回后产生 r2，不自动发布 REL01、关闭风险或认定战略贡献。

## 存档与权限

V0.3 使用独立 S/P/X/D 编号，不把旧 STR-DEMO/PRJ-/SYS- 直接改名。旧共享事实、会话、关注和材料仍留在原浏览器存储；页面切换到新目录，历史会话标出旧数据边界。无可见对应项的旧关注不影响新报告按职责回退汇总。重置演示仍是用户显式动作。

演示角色范围在返回实体与关系前过滤；系统管理员只有连接管理，不读取业务目录。组织关系不推导原文权限；应用只含授权摘要示例，不含真实评论或学习明细。浏览器端规则不是生产安全边界，真实后端鉴权尚未接入。
