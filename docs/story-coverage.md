## 本轮可看

- 管理层 → 工作台：目标摘要、领域筛选、项目表、关注入口、右侧看板、底部上下文对话；数据沿用现有演示对象，不为凑参考图数量虚增项目。
- 工作台 → 订单协同优化：目标与差距、大脑判断、需求与责任；「处理建议」展开原有决策和交付操作。
- 设置 → 切换演示身份 → 系统管理员：飞书、企微、Obsidian 的范围配置、模拟同步、失败重试、暂停、撤权和记录。没有真实授权、外部同步或定时执行。
- 新增需求：Owner 提交 → 产品补基线 → Owner 确认 → PM 排期 → 研发实现与提交 → EOS Agents 模拟审核 → 研发确认预览发布 → Owner 验收或退回。REQ-024 仍保留原来的详细工程演示链。
