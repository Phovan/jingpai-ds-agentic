## 本轮改动

1. 深色左栏和顶栏，浅色工作面；左侧不增加业务工具常驻菜单。
2. 六角色工作台分别显示角色目标、对象范围、差距和下一步；项目按领域分组。目标、实际、差距、状态、下一步拆成独立列。
3. 右侧关联看板随工作台、项目、需求、系统上下文切换；材料按需打开，与看板互斥。看板可以收起、打开、下钻、复制摘要。
4. 中间底部固定输入。围绕本体追问自动按对象ID建组，可继续旧会话或新开话题；不会自动批准业务动作。
5. 主动点击“生成看板”后，在当前角色空间保存上下文追踪入口；看板读取当前事实，不是固化报告。
6. 切换需求时同步底部和看板上下文；工作台筛选、页码保留；从对象返回工作台恢复本次滚动位置。

## 待补的点击验收路径

1. 管理层登录 → 工作台 → 领域 / 搜索 → 项目 → 打开右侧目标看板 → 关闭。
2. 项目底部提问 → 检查同名本体分组与上下文 → 返回本体 → 选择旧会话续聊 → 新话题仍在同一组。
3. 生成看板 → 右侧打开 → 复制分享摘要 → 刷新 / 重登同角色仍有入口；切换角色不出现该私人看板。
4. Owner工作台 → 需求 → 切换REQ-025 → 检查看板与输入上下文同步；回复及返回不能跳回REQ-024。
5. 研发工作台 → 订单平台 → 检查看板与系统上下文；原业务授权和验证门禁仍有效。
6. 材料 / 看板互斥切换；390px窄屏打开与关闭看板后，输入和导航仍可操作；键盘焦点能返回。
